# বাজার দর (BazarDor)

নিত্যপ্রয়োজনীয় পণ্যের সর্বশেষ দৈনিক বাজারদর ও বিভিন্ন বাজারের দামের তুলনামূলক প্ল্যাটফর্ম।

## প্রজেক্টের বৈশিষ্ট্যসমূহ

1. **লাইভ প্রাইস ট্র্যাকার**: ওয়েবসাইটের উপরে চলমান দাম পরিবর্তনের স্ক্রলিং স্ট্রিপ।
2. **দাম বৃদ্ধি ও হ্রাস পাওয়া পণ্য**: আজকের বাজারে সবচেয়ে বেশি দাম বৃদ্ধি ও কমে যাওয়া পণ্যের তালিকা।
3. **ক্যাটাগরি ও সর্টিং**: চাল, ডাল, তেল, সবজি ইত্যাদি ক্যাটাগরিভিত্তিক ব্রাউজিং এবং দাম কম-বেশি অনুযায়ী সাজানোর সুবিধা।
4. **বিস্তারিত পণ্যের বাজারদর**: প্রতিটি পণ্যের জাতীয় গড় দাম, সর্বোচ্চ ও সর্বনিম্ন দাম এবং বিভিন্ন বাজারের দামের তুলনামূলক চার্ট।
5. **অথেনটিকেশন ও প্রোফাইল**: সাধারণ ইমেইল/পাসওয়ার্ড এবং সোশ্যাল লগইন এবং প্রোফাইল তথ্য আপডেট করার সুবিধা।

## ব্যবহৃত টেকনোলজি

- Next.js 16 (App Router)
- React 19
- Tailwind CSS
- Lucide React
- React Hot Toast

## যেভাবে রান করবেন

১. ডিপেন্ডেন্সি ইন্সটল করুন:
```bash
npm install
```

২. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```

ব্রাউজারে http://localhost:3000 ওপেন করুন।
