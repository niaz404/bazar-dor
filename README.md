# 🛒 বাজার দর (BazarDor)

নিত্যপ্রয়োজনীয় পণ্যের সর্বশেষ ও নির্ভরযোগ্য দৈনিক বাজারদর পর্যবেক্ষণ এবং বাজারভিত্তিক দাম বিশ্লেষণ প্ল্যাটফর্ম।

---

## 📖 প্রজেক্ট পরিচিতি (Project Overview)

**বাজার দর (BazarDor)** হলো একটি আধুনিক ও ইন্টারেক্টিভ ওয়েব অ্যাপ্লিকেশন, যার মাধ্যমে বাংলাদেশের চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ ও মসলাসহ সকল নিত্যপ্রয়োজনীয় পণ্যের দৈনিক বাজারমূল্য, মূল্যের হ্রাস-বৃদ্ধি (▲/▼), জাতীয় গড় এবং বিভিন্ন বিভাগের বাজারের তুলনামূলক চিত্র সহজে পর্যবেক্ষণ করা যায়।

---

## ✨ মূল বৈশিষ্ট্যসমূহ (Key Features)

1. **📊 লাইভ প্রাইস ট্র্যাকার ও সেরা পরিবর্তন (Live Price Ticker & Risers/Fallers)**:
   - ওয়েবসাইটের শীর্ষে চলমান মূল্য পরিবর্তনের ইনফিনিট স্ক্রলিং মারকুই স্ট্রিপ।
   - আজকের বাজারে সবচেয়ে বেশি দাম বৃদ্ধি পাওয়া (Top Risers) এবং হ্রাস পাওয়া (Top Fallers) পণ্যের স্বয়ংক্রিয় তালিকা।

2. **🏷️ ক্যাটাগরি ফিল্টারিং ও বাংলা সংখ্যাভিত্তিক সর্টিং (Category & Bengali Numeral Sorting)**:
   - ক্যাটাগরিভিত্তিক আলাদা পেজ ও লোডিং কঙ্কাল অ্যানিমেশন (Skeleton Loader)।
   - বাংলা সংখ্যা অনুধাবন করে কম থেকে বেশি ও বেশি থেকে কম সঠিক নিউমেরিক্যাল সর্টিং সুবিধা।

3. **🔒 বিস্তারিত পণ্য বিশ্লেষণ ও বাজারভিত্তিক আজকের দাম (Detailed Product Breakdown)**:
   - সুরক্ষিত রুট (Protected Route) যা শুধুমাত্র লগইনকৃত ব্যবহারকারীদের পণ্যের বিস্তারিত দেখার সুযোগ দেয়।
   - জাতীয় সর্বনিম্ন, সর্বোচ্চ ও গড় দামের কার্ড এবং বিভিন্ন বাজারভিত্তিক তুলনামূলক মূল্য তালিকা।

4. **🔐 অথেনটিকেশন ও সোশ্যাল লগইন (Authentication & Social Sign-In)**:
   - ইমেইল ও পাসওয়ার্ডের মাধ্যমে সাইন ইন এবং সাইন আপ।
   - গুগল ও গিটহাব সোশ্যাল লগইন বাটন এবং ইন্টারেক্টিভ টোস্ট নোটিফিকেশন (`react-hot-toast`)।

5. **👤 ইউজার প্রোফাইল ও তথ্য পরিবর্তন (User Profile & Update Information)**:
   - ব্যবহারকারীর প্রোফাইল তথ্য প্রদর্শন এবং সরাসরি নাম আপডেট করার সুবিধা ও তাৎক্ষণিক সেশন সিঙ্ক।

## 🛠️ ব্যবহৃত প্রযুক্তি (Technologies Used)

- **Frontend Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS, Google Font (Hind Siliguri)
- **Icons**: Lucide React
- **Notifications**: React Hot Toast
- **Authentication**: BetterAuth / Custom Auth Context
- **Data Fetching**: REST API (Cloudflare Workers)

## 🚀 লোকাল সেটআপ ও রান করার নিয়ম (Getting Started)

### ১. রিপোজিটরি ক্লোন করুন এবং প্রজেক্ট ফোল্ডারে প্রবেশ করুন:
```bash
git clone <repository-url>
cd assignment
```

### ২. ডিপেন্ডেন্সি ইন্সটল করুন:
```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```

ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করে প্রজেক্টটি দেখুন।
